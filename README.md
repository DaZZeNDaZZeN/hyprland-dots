# hyprland-dots

### keybindings:
<p>
Exit hyprland: SUPER + M <br> 
Close window: SUPER + C <br>
Open terminal: SUPER + T or CTRL + ALT + T <br>
Open browser: SUPER + W <br>
Open app launcher: SUPER + R <br>
Open noctalia window switcher: ALT + GRAVE <br>
Next workspace: ALT + TAB <br>
Previous workspace: ALT + SHIFT + TAB <br>
Move window to next workspace: ALT + CTRL + TAB <br>
Move window to previous workspace: ALT + CTRL + SHIFT + TAB <br>
Move focus between windows: SUPER + left right up down arrow keys <br>
Open workspace {n}: SUPER + {n}  (SUPER + 1 for first, SUPER + 2 for second and so on) <br>
Move window to workspace {n}: SUPER + SHIFT + {n} <br>
Make window float: SUPER + B <br>
Make window go fullscreen: SUPER + F <br>
Make window occupy all space(maximize window): SUPER + G <br>
Screenshot: SUPER + SHIFT + S <br>
Open notifications: SUPER + N <br>
Open Control Center: SUPER + H <br>
Open session panel: SUPER + Z <br></p>


### required packages for arch linux:

<p>
wm: hyprland <br>
shell: noctalia <br>
terminal: alacritty <br>
file manager: dolphin <br>
browser: firefox <br>
qt6 styling: qt6ct-kde (from aur) <br>
<br>
<br>
Cursor pack directory should be located in ~/.local/share/icons/</p>
